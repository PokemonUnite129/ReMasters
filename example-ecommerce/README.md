# Example PHP AJAX E-Commerce Demo

This folder contains a small demo of a modern e-commerce page using PHP, HTML/CSS and jQuery for AJAX interaction.

* `index.php` – Main page that loads products via AJAX.
* `fetch_products.php` – Returns a JSON list of products.
* `add_to_cart.php` – Adds products to a session-based cart and returns the count.
* `style.css` – Basic styling for the layout.
* `scripts.js` – jQuery logic to render products and handle cart actions.

This example is meant for demonstration and does not include persistent storage.
